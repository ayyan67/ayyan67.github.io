Projects

Islamic Bank

An economy bot for muslim.chat, a large Muslim community on Discord: wallets, savings, prayer check-ins with streaks, trivia and a shop.

It replaced NadekoBot, which the server had used since 2018. I migrated 85,000 users and 383,000 old ledger rows so nobody lost a balance. Every coin movement is an append-only ledger entry, written so that a retried command can’t pay out twice. Since launching in February 2026 it has recorded about 252,000 transactions and 13,000 prayer check-ins. Releases ship from GitHub Actions to a VPS as immutable builds with a one-step rollback and nightly backups.

TypeScript, Seyfert, SQLite, Vitest, GitHub Actions. In production since February 2026, 193 commits.

Pagerlite

An on-call assistant that investigates an outage, proposes a fix, and runs it only after a person approves.

The model can read metrics, logs, deploys and feature flags freely, but it can change things through exactly one tool, and that tool waits for a human. An approved fix runs as a durable workflow that applies the change, checks that the service recovers, and reverts on its own if it doesn’t. Resolved incidents are saved as postmortems the agent recalls next time. The servers are simulated, so the demo is safe to click through.

TypeScript, Cloudflare Workers AI (Llama 3.3 70B), Agents SDK, Workflows, Durable Objects. 39 unit tests.

CryptoSim

An iPhone app for paper trading: start with $10,000 of pretend money and trade on live crypto prices.

I first built it for a university iOS course, then rebuilt it the way I’d want production code to look. Every service is injected through a protocol, so the test suite runs offline in under a second. Network calls have typed errors and backoff that never retries a rate limit, overlapping refreshes are merged into one, and prices stay on screen when a refresh fails. A debug screen shows p50 and p95 latency and the analytics event stream.

Swift, SwiftUI, SwiftData, async/await, XCTest. Runs without an API key.

Masha Studios

The online store for my sister’s clothing label. It takes real orders.

There’s no database. Stock for each size is worked out from paid, unrefunded Stripe Checkout sessions, so a webhook delivered twice can’t count a sale twice. The browser only says which items and sizes are in the bag, and the server sets the prices. I verify Stripe’s webhook signatures myself, handle payment methods that settle later such as Klarna and Affirm, and send order emails after replying to Stripe so a slow email can’t trigger a retry.

Next.js, TypeScript, Stripe Checkout, Resend, Vercel.

Astra Medical

A medical-billing startup where I was lead developer from 2023 to 2025.

I built the claims pipeline. Claude on AWS Bedrock reads scanned superbills, a biller confirms the extracted fields step by step, and the app generates standard 837P claim files, submits them to the clearinghouse over SFTP, and reads back the status and payment reports. Claims that used to take two weeks went out in under ten minutes. The code belongs to the company, so it isn’t public.

Next.js, TypeScript, Supabase, AWS Bedrock.
