Pagerlite

An on-call assistant that investigates an outage, proposes a fix, and only runs it after a person says yes.

The model can read metrics, logs, deploys and feature flags as much as it likes, but the only way it can change anything is through one tool, and that tool blocks until a human approves. An approved fix runs as a durable workflow: apply the change, watch the service, and revert on its own if it doesn’t recover. Each resolved incident is written up as a postmortem the agent can search the next time something similar happens. The servers are simulated, so you can click through the demo without breaking anything.

Islamic Bank

The economy bot for muslim.chat, a large Muslim community on Discord: wallets, savings, prayer check-ins with streaks, trivia and a shop.

The server had run its economy on NadekoBot since 2018, and I replaced it. The migration moved 85,000 users and 383,000 old ledger rows across without anyone losing a balance. Every coin movement is an append-only ledger entry, written so that a retried command can’t pay out twice. Since February 2026 it has recorded about 252,000 transactions and 13,000 prayer check-ins. Releases go from GitHub Actions to a VPS as immutable builds with a one-step rollback, and the database is backed up nightly.

Local LLMs on an Intel Arc A770

A 35-billion-parameter model with vision and tool calling, running on a $300 GPU, and the notes from getting it there.

I bought an Arc A770 because 16 GB of VRAM was cheap, and Intel’s software support is the price you pay for that. Most of this project was working out what actually runs. The answer turned out to be Qwen3.6-35B-A3B, a mixture-of-experts model whose experts spill into system RAM without the speed collapsing, at 64K context with image input and tool calling, generating about 19 tokens a second. Getting there meant finding that Intel’s Vulkan driver advertises a cooperative-matrix extension that silently turns any prompt over about 10,000 tokens into garbage (two open llama.cpp issues, and the workaround is now baked into every launcher), measuring SYCL against Vulkan on each driver release, and learning that a dense model has to fit entirely in VRAM or throughput drops by two thirds. One night Windows Update rolled the driver back three versions and broke the SYCL build. The notes cover that too.

The model is the brain of a Hermes agent I talk to over Telegram. I wrote three skills for it: a scored digest of new job postings, a read-only receipt lookup in Gmail, and a marketplace lister that drafts a listing from photos and stops short of posting it. The spec is mostly about where the agent stops and I take over.

arc-whisper

Speech to text on the same GPU: a 2024 PyTorch script, rebuilt in 2026 as two offline apps on whisper.cpp.

The first version pushed OpenAI’s Whisper through Intel’s PyTorch extension to transcribe and translate Japanese audio. That stack is end-of-life now, so the new version compiles whisper.cpp with Intel’s SYCL toolchain and puts two apps on top. LocalFlow is push-to-talk dictation: hold a key, talk, let go, and the text lands in whatever window has focus. Its keyboard hook is 51 lines of C, because a hook installed from Python stalls every keyboard on the system whenever the interpreter is busy. The model unloads after ten idle minutes so it never fights a game for VRAM.

Scribe records meetings, transcribes them with large-v3, and works out who said what from the voices. On a four-person meeting from the AMI corpus it found all four speakers with 2.7% confusion, against 16% for the library’s built-in clustering. A local Qwen pass then fixes misheard words, but every edit is diffed against what Whisper heard and thrown out if it drops or rewrites more than a few words. I added that check after the model tried to delete 18 words from one line. I also tried letting it reassign speakers. All five of its changes were wrong, so speaker labels come from the audio only.

Prayer Reminder

A Windows tray app that reads the iqamah times your masjid publishes and tells you when to leave.

My masjid posts its times on its website and I kept missing the walk over, so I wrote this. It’s C against Win32 directly: one 270 KB executable, no runtime, no installer. It reads the JSON feed behind the Masjidal widget that most masjid sites embed, caches two weeks of times so it works offline and across midnight, and schedules today’s and tomorrow’s reminders so a 4:30 AM Fajr alert is already queued before the date changes. After the machine wakes from sleep it skips anything stale rather than firing a burst of old alerts. Fridays swap Dhuhr for whichever Jumu’ah you attend. You can pause it from the tray and snooze it from the popup, which is a per-pixel-alpha layered window with properly antialiased corners and no GDI+.

It ships pointed at my masjid in New Jersey, but any masjid on Masjidal works with a three-line config change. The app notices the edit, reloads, and fetches the new times without a restart.

Masha Studios

The online store for my sister’s clothing label. It takes real orders.

There’s no database. Stock for each size is worked out from paid, unrefunded Stripe Checkout sessions, so a webhook delivered twice can’t count a sale twice. The browser only says which items and sizes are in the bag; the server sets the prices. I verify Stripe’s webhook signatures myself, handle payment methods that settle later such as Klarna and Affirm, and send the order email only after replying to Stripe, so a slow email can’t trigger a retry.

CryptoSim

An iPhone app for paper trading: start with $10,000 of pretend money and trade on live crypto prices.

It started as a university iOS project. I then rebuilt it the way I’d want production code to look: every service is injected through a protocol, so the test suite runs offline in under a second. Network calls have typed errors and a backoff that never retries a rate limit, overlapping refreshes are merged into one, and prices stay on screen when a refresh fails. A debug screen shows p50 and p95 latency and the analytics event stream.
