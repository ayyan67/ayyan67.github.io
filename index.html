Islamic Bank

An economy bot for muslim.chat, a large Muslim community on Discord: wallets, savings, prayer check-ins with streaks, trivia and a shop.

It replaced NadekoBot, which the server had used since 2018. I migrated 85,000 users and 383,000 old ledger rows so nobody lost a balance. Every coin movement is an append-only ledger entry, written so that a retried command can’t pay out twice. Since launching in February 2026 it has recorded about 252,000 transactions and 13,000 prayer check-ins. Releases ship from GitHub Actions to a VPS as immutable builds with a one-step rollback and nightly backups.

TypeScript, Seyfert, SQLite, Vitest, GitHub Actions. In production since February 2026, 193 commits.

Pagerlite

An on-call assistant that investigates an outage, proposes a fix, and runs it only after a person approves.

The model can read metrics, logs, deploys and feature flags freely, but it can change things through exactly one tool, and that tool waits for a human. An approved fix runs as a durable workflow that applies the change, checks that the service recovers, and reverts on its own if it doesn’t. Resolved incidents are saved as postmortems the agent recalls next time. The servers are simulated, so the demo is safe to click through.

TypeScript, Cloudflare Workers AI (Llama 3.3 70B), Agents SDK, Workflows, Durable Objects. 39 unit tests.

CryptoSim

An iPhone app for paper trading: start with $10,000 of pretend money and trade on live crypto prices.

I first built it for a university iOS course, then rebuilt it the way I’d want production code to look. Every service is injected through a protocol, so the test suite runs offline in under a second. Network calls have typed errors and backoff that never retries a rate limit, overlapping refreshes are merged into one, and prices stay on screen when a refresh fails. A debug screen shows p50 and p95 latency and the analytics event stream.

Swift, SwiftUI, SwiftData, async/await, XCTest. Runs without an API key.

Local LLMs on an Intel Arc A770

Running a 35-billion-parameter model with vision and tool calling on a $300 GPU, and the notes on what it took.

Intel’s Arc cards are cheap for 16 GB of VRAM but poorly supported, so most of the work is finding out what actually runs. I settled on Qwen3.6-35B-A3B, a mixture-of-experts model whose experts offload cleanly to system RAM, at 64K context with image input and tool calling, generating at about 19 tokens a second. Along the way I found that Intel’s Vulkan driver advertises a cooperative-matrix extension that silently turns any prompt over about 10,000 tokens into garbage, matched it to open llama.cpp issues, and built the workaround into every launcher. I measured SYCL at twice Vulkan’s prompt-ingest speed but half its generation speed, and showed that a dense model must fit entirely in VRAM or throughput drops threefold. When Windows Update quietly rolled the driver back three versions and broke the SYCL build, the notes caught that too.

On top of it runs a Hermes agent, NousResearch’s open framework, reachable over Telegram, with three skills I wrote: a scored digest of new job postings, a read-only lookup of purchase receipts in Gmail, and a marketplace lister that drafts a listing from photos and stops before anything is posted. The pipeline spec draws the line between what the agent may do on its own and what waits for me.

llama.cpp (SYCL and Vulkan builds), Qwen3.6-35B-A3B, hermes-agent, ComfyUI on PyTorch XPU. Benchmark tables and raw logs are in the repo.

arc-whisper

Speech to text on an Intel Arc GPU: a 2024 PyTorch script, rebuilt in 2026 as two offline apps on whisper.cpp.

The first version ran OpenAI’s Whisper through Intel’s PyTorch extension to transcribe and translate Japanese audio. The new version compiles whisper.cpp with Intel’s SYCL toolchain and puts two apps on top. LocalFlow is push-to-talk dictation: hold a key, speak, release, and the text is pasted into whatever has focus. Its keyboard hook is 51 lines of C, because a Python hook stalls every keyboard on the system whenever the interpreter is busy, and the model unloads after ten idle minutes so it never fights a game for VRAM.

Scribe records meetings, transcribes them with large-v3, and labels who said what from the voices. On a four-person meeting from the AMI corpus it found all four speakers with 2.7% confusion where the library’s own clustering had 16%. A local Qwen pass then fixes misheard words, but every edit is diffed against what Whisper heard and rejected if it drops or rewrites more than a few words, after the model once tried to delete 18 words from a line. I also tested letting the model reassign speakers: all five of its changes were wrong, so speaker labels come from the audio only.

Python, C, whisper.cpp SYCL build, sherpa-onnx, Silero VAD. Nothing leaves the machine.

Prayer Reminder

A Windows tray app that reads the iqamah times your masjid publishes and tells you when to leave for the congregation.

I wrote it in C against Win32 directly, so it is one 270 KB executable with no runtime and no installer. It reads the JSON feed behind the Masjidal widget that most masjid websites embed, caches two weeks of times so it works offline and across midnight, and schedules today’s and tomorrow’s reminders so a 4:30 AM Fajr alert is queued before the day changes. The tick never fires a burst of stale alerts after the machine wakes from sleep. It handles Jumu’ah on Fridays, pauses from the tray, and snoozes from the popup. The popup is a per-pixel-alpha layered window with antialiased corners drawn without GDI+.

It ships pointed at my masjid in New Jersey, but any masjid on Masjidal works by editing three lines of config: the app notices the edit, reloads, and fetches the new times without a restart.

C11, Win32, WinHTTP, GDI. 3,300 lines, builds with one gcc command.

Masha Studios

The online store for my sister’s clothing label. It takes real orders.

There’s no database. Stock for each size is worked out from paid, unrefunded Stripe Checkout sessions, so a webhook delivered twice can’t count a sale twice. The browser only says which items and sizes are in the bag, and the server sets the prices. I verify Stripe’s webhook signatures myself, handle payment methods that settle later such as Klarna and Affirm, and send order emails after replying to Stripe so a slow email can’t trigger a retry.

Next.js, TypeScript, Stripe Checkout, Resend, Vercel.
